# To-Do List (Python - Console)

## Description
Ce projet est une application console de gestion de tâches (To-Do List).  
L'utilisateur peut ajouter, supprimer, modifier, cocher et lister ses tâches à faire ou déjà faites.

## Objectif
J'ai réalisé ce projet pour m'entraîner à :
- manipuler des listes et boucles
- gérer l’entrée utilisateur
- créer un mini système interactif avec commandes
- organiser un projet un peu plus long avec plusieurs fonctionnalités

## Fonctionnalités
- Ajouter une tâche (`add`)
- Supprimer une tâche (`delete`)
- Modifier une tâche (`modify`)
- Marquer une tâche comme faite (`check`)
- Afficher les tâches à faire (`list`)
- Afficher les tâches faites (`done_list`)
- Supprimer toutes les tâches (`clear_tasks` / `clear_done`)
- Afficher l’aide avec toutes les commandes (`help`)

## Fonctionnement
1. L’utilisateur tape une commande
2. Selon la commande, l’application effectue l’action correspondante
3. Le programme continue en boucle pour permettre plusieurs opérations
4. Les listes sont mises à jour en temps réel

## Technologies utilisées
- Python
